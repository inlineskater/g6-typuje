# "Wszystkie Gry" picker — full design doc

Full detail on the free-forever arcade storefront tab. CLAUDE.md keeps a short summary.

### „Wszystkie Gry" picker (`#tab-all-games`)

The free-forever arcade tab is a **storefront**, not a list of links (2026-07-26 rework). `#ag-picker` opens with the **🏆 Klasyfikacja generalna** podium (`#ag-podium`) and then one wide card per game; picking a card still moves that game's seasonal panel into `#ag-game-slot` exactly as before.

- **Live gameplay previews (`games/previews.js`).** There are no recorded GIFs anywhere in the repo. Each card's `.ag-card-media` runs a small autoplaying attract-mode that **renders through the game's own draw function**, so a preview can never drift from how the game actually looks. The mechanism is a per-frame **global hijack**: `games/*.js` hold their canvas context and runtime in top-level `let` bindings (one global lexical scope across classic scripts), so each `AGP_DEFS[game].draw(p)` swaps e.g. `ttCtx`/`tetrisRuntime` for the preview's canvas + a throwaway runtime, calls `tetrisDraw()`, and restores both in a `finally` — synchronous, so a real round can never observe the swap. Motion comes from preview-only bots: the **real, pure simulation** runs for `tetris`/`egg_catch`/`super_mariusz`/`popup_panic` (`ttAdvanceTick`, `ecAdvanceTick`, `smAdvanceTick` replaying `AGP_SM_GOLDEN` — the verified completing run from `scripts/sm-parity.mjs` — and `ppAdvanceTick`), while `snake`/`flappy_pants`/`invoice_horde`/`bug_jumper` use light stand-in steps that mutate the same runtime shape the draw code reads (their real step functions submit scores and write HUD nodes). `whack_boss` and `popup_panic` are DOM games: their previews build the real `.wb-arena`/`.pp-arena` markup (the boss is cloned from `#wb-target`, popups come from `popupPanicCreateEl`) at native size and scale it with `agpScaleDom`. Nothing calls `begin*`/`finish*`/`stop*Round`, so no round is started and no score is submitted. The engine is one shared 30 fps RAF loop gated by an IntersectionObserver (only cards on screen animate), paused on `document.hidden`, on `agpStopPreviews()` (leaving the picker or opening a game), and entirely under `prefers-reduced-motion` — where each preview still paints one static frame. `previews.js` itself is lazy-loaded by `ensurePreviewScript()`, and every call site tolerates it never loading. A def may set `view(p)` to zoom the base fit — Bug Jumper's 56×32 board is unreadable in a thumbnail, so its preview follows the climber at 2.6×.
- **Records, two columns per card** (`loadArcadePickerScores` → `renderArcadePickerScores`): **all-time first, then this week**, top `AG_PICKER_TOP_N` (5) each, with a „Pokaż wszystkich (N)" toggle per card (`agPickerExpanded`). Two paged reads cover every game in the picker (13 as of 2026-08) — `arcade_leaderboard` (already best-per-user-per-game, so it doubles as the `user_id → nick` map) and `arcade_scores` filtered to the running week via `agWeekStartISO()` (Monday 00:00 Europe/Warsaw, derived from `currentSeasonWeekStartStr()`), folded to each player's weekly best. Results cache for 60 s; `recordArcadeScore` resets `agPickerScoresAt` so a fresh run shows up on the way back.
- **Klasyfikacja generalna** (`agMedalTable`/`renderArcadePodium`) is an **Olympic medal table, all-time only** — raw scores can't be summed across games (30 is a perfect Bug Jumper run and nothing in Tetris), so each game's all-time top three hand out 🥇🥈🥉 and players are ordered by golds, then silvers, then bronzes, then nick. The podium renders 2nd/1st/3rd with each medalist's gold-game emojis, read from the cards themselves via `agGameLabels()` (no duplicated game-name constant).
- **Arcade-only games** (`bubble_breaker`, and `filler`/`healer_dungeon` before their promotions) live here without any seasonal stack: no `*-action` Edge Function, no `*_rounds`/`*_scores` tables, no weekly award. Their panels still sit with the seasonal panels in `#tab-whack-boss` so promoting one later is a `SEASONAL_ROTATION` entry rather than moving markup, and `loadSeasonalTab()` hides them unconditionally (there is no `is*` flag to test). The score path is the plain arcade one — `payArcadeEntry()` before the round, `recordArcadeScore()` after — which means it is **client-reported**, and the per-game cap in `supabase/arcade.sql` is the only guard. Adding one is: a `games/*.js` file, a panel, a card, entries in `LAZY_GAME_SCRIPTS`/`AG_PANEL_IDS`, a pre-declared `let *Runtime`, a `stop*Round()` stub plus that call added to the four stop-lists, an `AGP_DEFS` preview, and the game type added to **both** RPCs in `arcade.sql` (`pay_arcade_entry`'s whitelist and `record_arcade_score`'s cap) — re-run that file, it is idempotent.
- The cards are `role="button"` divs, **not `<button>`s** — the „Pokaż wszystkich" toggle has to be a real nested button, and the previews mount real DOM inside the card. Click and Enter/Space both call `selectAllGame`; clicks inside `.ag-sb-more` are ignored. `formatArcadeScore` renders `super_mariusz` as a course percent (`smProgressPct`) since its stored score is tile columns.
